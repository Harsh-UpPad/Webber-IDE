# The perfect IDE that combines HTML, CSS, JS/TS into one, clean view! 
## Features
- You can see all of your Ids and classes without scolling even a tiny bit!
- It only cost about 8 megabytes to install.
- Color
- HTML view
- Support for HTML, CSS, JS, and TS
## The code
The code should mostly be TS for the logic, with rust there to speed things up, and HTML and CSS for the interface.
- main.ts: Connects and adds functionality to the IDE.
- color.ts: Defines the color theme and applies those to HTML, CSS, JS, and TS files
- parser.ts: Classes for the Id/Classes inspecter part.
